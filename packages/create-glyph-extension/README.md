# create-glyph-extension

Scaffold a new [Glyph](https://glyph.moe) novel reader extension project.

## Requirements

- Node.js >= 20

## Usage

```bash
npx create-glyph-extension my-extensions
cd my-extensions
npm run dev
```

The interactive prompt will ask for:

- **Project name** - directory name for your project
- **Source ID** - lowercase identifier (e.g. `royalroad`)
- **Display name** - human-readable source name
- **Language** - language code (default: `en`)
- **Author** - your name
- **GitHub repo URL** - optional, for automatic GitHub Pages URL generation
