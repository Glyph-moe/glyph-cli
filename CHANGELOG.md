# Changelog

## 1.0.0 (2026-04-10)

### Features
- `create-glyph-extension` -- scaffold new extension projects with interactive prompts
- `glyph dev` -- development server with hot reload, LAN discovery, and `--open` flag
- `glyph build` -- production builds with IIFE bundling, validation, and `dist/index.json` generation
- `glyph test` -- vitest wrapper with embedded runtime setup (no manual `test-setup.js` needed)
- `glyph validate` -- validate extensions with `--typecheck`, `--fix`, `--ci`, `--tests`
- `glyph add` -- scaffold new sources in existing projects with interactive prompts
